# UI 修订设计图生成说明（V1 已过时）

用户已更正：精简仅显示倒计时，展开顺序为倒计时、公告、日历。以下为 V1 生成记录，V2 以 `m3-ui-revision-layout.svg` 和方案文档为准。

工具：内置 Image Gen，先生成完整设计板，再针对公告固定高度和圆环 Logo 修正。只用于设计评审，不作为运行界面的贴图。

生成要求：Windows 11 Fluent 桌面小组件；中文；三列深色精简、浅色精简、深色展开；附长公告内部滚动示例与空心倾斜／实心竖直置顶图标对照。所有公告卡片等宽等高，紧凑窗口大小一致，展开从公告下方增加预计时间和日历。保留现有蓝色圆环 Logo。

颜色：深色窗口 #202124、卡片 #2B2D30、文字 #F3F3F3、强调 #60CDFF；浅色窗口 #F3F3F3、白色卡片、文字 #1A1A1A、强调 #0067C0。400 DIP 宽，标题 42、公告标题 28、公告卡片 190、页脚 28；边距 12、间距 8。正文 14、倒计时 32。公告正文独立滚动，发布时间和查看原文固定。

内容：Codex Reset；重置公告；Tibo；@thsottiaux；公开公告；查看原文；Codex Resets；下一次公告重置；距公告预计时间；额度直接重置；限额重置券；预告；实际额度以 Codex 为准。示例日期和原文用于演示，不代表当前事件。

约束：取消历史公告和返回最新；不显示本地时间或 UTC 标签；不显示全局、备用或观察身份；精简只显示公告；上下箭头控制模式，左右箭头翻阅；固定高度不得因长文或模式变化而改变。没有多余口号、装饰性仪表盘或夸大个人重置成功的文案。

修正要求：展开公告高度与精简公告对齐；长文示例也同高；圆环 Logo 不得变成双箭头；原文账号严格拼写；十月六行日历末行为灰色 2–8。
