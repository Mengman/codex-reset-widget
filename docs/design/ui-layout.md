# 当前 UI 布局

更新日期：2026 年 10 月 2 日。本文描述当前发布候选版的窗口布局、文案和交互规则。

![当前 UI 布局示例](widget-layout.png)

[SVG 尺寸稿](widget-layout.svg)

板块顺序：重置倒计时 → 重置公告 → 重置日历。应用采用蓝白极简计时器 Logo，详见 [Logo 源图](countdown-logo.svg)。

## 1. 精简与展开

首次启动默认精简，仅显示标题栏、重置倒计时、来源／更新时间。公告和日历在用户展开后显示。

两种模式保持同宽，倒计时板块的位置、高度和排版一致。展开后在倒计时下方依次追加公告、日历；倒计时不因切换模式而重新排版。之后启动恢复用户最后一次精简／展开选择；已有设置沿用最后选择，不在升级时强制收起。

尺寸使用 DIP，屏幕上随 Windows 缩放：宽 400，精简高约 292，展开高约 840。六行月历纳入展开尺寸。窗口受工作区高度约束，用户调整后的展开尺寸会保存。

| 部分 | 目标尺寸／规则 |
| --- | --- |
| 窗口边距 | 12 DIP；卡片底边到下一板块标题顶部 16 DIP；标题到卡片 10 DIP |
| 标题栏 | 42 DIP；图标 16，按钮 28×28，名称 16 |
| 公告标题 | 28 DIP，文字 16；右侧上一条／下一条 |
| 公告卡片 | 固定 190 DIP，不随内容长度变化 |
| 公告作者行 | T 文字头像、Tibo、@thsottiaux、公开公告 |
| 公告正文 | 独立固定视口，14 DIP，约 21 DIP 行高；超出内部滚动 |
| 公告底行 | 发布时间与查看原文，固定在底部，不随正文滚动 |
| 重置倒计时 | 固定 200 DIP；倒计时 48 DIP；日期 19 DIP；时长说明 13 DIP；预计时间标签 12 DIP |
| 日历 | 六行日期，日期行约 29 DIP，六行最后一行补位日期降低视觉权重；选中日详情采用紧凑列表 |
| 页脚 | 约 28 DIP，来源在左、更新时间在右，紧接内容 |

短公告保持卡片高度，不撑大窗口；长公告不会推动日历。卡片作者行约 40 DIP、正文视口约 100 DIP、底行约 22 DIP，其余为内边距。正文区域始终保留滚动条槽位，出现滚动条时不改变正文宽度。翻阅新公告时正文回到开头；展开／收起和主题切换保持当前公告阅读位置。展开区域在小工作区可整体滚动，标题栏保持可操作。

## 2. 公告统一

- 标题始终是“重置公告”，删除“历史公告”和“返回最新”。
- `‹` 查看更早的公告，`›` 查看更新的公告；到列表边界时禁用对应按钮。工具提示写“上一条（更早）”“下一条（更新）”。
- 初次启动读取当前最新公告；自动刷新保持用户正在阅读的条目，不强制跳到最新。浏览公告不改变预计时间板块。
- 展示统一为“公开公告”，作者行统一为 Tibo / `@thsottiaux`，使用现有 T 文字头像。用户消息中的账号拼写与实际来源不同，采用数据源现有的 `@thsottiaux`。
- 回复帖、转推属于公开内容，界面不再因为接口标记 `observed` 自动换成“观察记录”头像。开发时核对原文链接与归属；内部保留来源类型及证据，避免把缺少原文的纯观察信号误当作 Tibo 发言。无可核对原文的记录不伪造作者或原文链接。

## 3. 重置分类

| 接口类别 | 新名称 | 解释／工具提示 | 标记 |
| --- | --- | --- | --- |
| regular | 额度直接重置 | 直接重置当前使用额度；实际到账以 Codex 为准 | 蓝色圆点 |
| banked | 限额重置券 | 发放一次可手动使用的重置机会；可用期限以 Codex 为准 | 橙色菱形 |
| 未来预告 | 预告 | 尚未到公告预计时间 | 空心标记 |

“限额重置券”是界面中的解释性名称，首次解释和工具提示补充“手动使用”，不表示真正的兑换码。日期详情可以显示“限额重置券 · 手动使用”。不再使用“全局”“备用”；所有板块、图例和菜单保持一致。未识别类型保留“类型待确认”，避免错误归类。

数据源对 banked reset 的说明是可由用户自行使用、不会立即补充额度的重置机会。[Codex Resets](https://codex-resets.com/)。不根据历史记录推断用户持有几次机会，也不自行推断失效时间。

## 4. 时间和置顶

日期继续按电脑系统时区转换；删除倒计时板块可见的“本地时间 · UTC+XXXX”。时区详情只在时间工具提示中提供，正文原文保持不变。

到点前：标题“重置倒计时”，右上“已预告”；居中 48 DIP 大数字，下方紧接“距公告预计时间”。再往下独立显示“公告预计时间”标签与 19 DIP 日期／时间；卡片底行左侧显示重置类型，右侧显示“实际额度以 Codex 为准”。日期与剩余时长分别居中展示，底部两项说明保持同一行。到点后：标题“最近公告的预计重置时间”，以日期／时间替换倒计时，显示“实际额度以 Codex 为准”。板块高度保持稳定。

置顶关闭：倾斜的空心图钉，普通文字色，工具提示“置顶窗口”。置顶开启：竖直的实心图钉，强调色，浅强调底，工具提示“取消置顶（当前已置顶）”。形状和方向均变化，不能只靠颜色识别。

标题栏保留刷新、置顶、精简／展开、更多、关闭。菜单提供主题、语言、开机启动、收进托盘、来源、关于和退出；不提供最小化操作。关闭仍收进托盘，显式退出仍从菜单选择。

## 5. 主题和设计检查

采用蓝白计时器 Logo、Windows 11 圆角、细边框和深浅色资源。减少字体层级和空白，公告正文不因压缩尺寸而缩小。高对比度继续使用系统颜色与可辨认的图形。

当前布局示例使用 SVG 表达深色精简、浅色精简、深色展开的排版；示例内容及时间不代表真实事件。公告固定高度、内部滚动与置顶图标的规则仍保留。当前测试结果与未验证环境见 [验证记录](../validation.md)。

布局要点：仅倒计时的精简模式、倒计时、公告、日历的顺序、400 DIP 宽度、固定公告高度、重置分类命名和置顶图标。

## 6. 图标统一

标题栏的刷新、置顶、展开／收起、更多和关闭，以及公告翻页和日历翻月，全部采用矢量图形，不再混用字体符号。

- 图标画布统一 16×16 DIP，按钮统一 28×28 DIP，居中内边距 6 DIP。
- 线性图标统一 1.5 DIP 线宽，圆角端点和连接。
- 左右翻页共用同一组箭头路径，公告与日历显示完全相同。
- 置顶保留空心倾斜／实心竖直方案，选中背景大小与其他按钮一致。
- 刷新、关闭和箭头按同一视觉尺度绘制；更多使用三个固定圆点，不受字体影响。

图标、固定卡片高度、长文滚动和板块间距由桌面检查覆盖，见 [验证记录](../validation.md)。

## 双语布局

[英文设计图](widget-layout.en.png)及[英文 SVG](widget-layout.en.svg)对应同一尺寸与图标规范；不包含文字的 Logo 由两种语言共用。英文 README 使用英文设计图，中文 README 使用中文设计图。

英语与简体中文使用相同卡片高度和板块间距。短标签采用自适应宽度，长说明允许换行；日期按当前界面语言格式显示。切换语言保留公告正文滚动和日历选择。
