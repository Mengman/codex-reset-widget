Codex Reset Widget 0.3.2-m3
Windows 11 x64 · 自带 .NET 10 运行时

完整解压后运行 CodexResetWidget.exe。默认读取真实公开公告。

桌面操作
- 首次启动默认精简，只显示倒计时；之后恢复上次选择。公告固定高度，长文内部滚动。
- 额度直接重置表示直接重置当前额度；限额重置券表示可手动使用的重置机会，期限以 Codex 为准。
- 标题栏空白、名称和图标区域可拖动；右上角图钉切换置顶，箭头切换展开／紧凑。
- “…”菜单中的“最小化”，“×”关闭后收进托盘，首次关闭会显示说明。
- 点击托盘图标或右键“显示窗口”恢复；托盘右键可刷新数据、收进托盘或退出。
- 彻底退出请选择窗口“…”菜单或托盘菜单中的“退出”。
- 隐藏和最小化停止秒级显示更新，后台仍按原周期检查公告和历史。
- 恢复窗口时重新读取时区并计算时间，倒计时到点后显示最近公告的预计重置时间。
- 关闭后保留窗口模式、展开尺寸、位置、置顶及主题；下次启动恢复。
- 显示器断开或工作区变化后，将窗口调整到可用屏幕内。

阅读与主题
- 公告标题旁的左右箭头阅读较早／较新的已收录公告；顶部公告板始终显示当前预告。
- 选择日历中的日期和当天记录可以阅读历史；公告左右箭头自由翻阅，标题始终为“重置公告”。
- 切换模式、主题和刷新保留阅读对象、月份和展开滚动位置。
- “…”菜单可选跟随系统、浅色或深色主题；高对比度模式采用系统颜色。
- Windows 支持且允许透明效果时使用 Mica 背景；其他情况使用不透明背景。

数据与升级
%LocalAppData%/CodexResetWidget/settings.json 保存桌面设置。
cache/snapshot.json 保存数据缓存，logs/ 保存有限大小的诊断日志。
退出后将新版完整解压到新目录运行，继续使用兼容的设置和缓存。
真实时间跟随电脑时区；实际额度请以 Codex 中显示为准。
