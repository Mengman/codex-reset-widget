Codex Reset Widget 0.1.0-m1
Windows 11 x64 · 自带 .NET 10 运行时

这是 M1 界面与时间行为原型，所有日期、倒计时、公告与日历记录都是模拟数据。

使用方法
1. 将 ZIP 完整解压到一个目录，双击 CodexResetWidget.exe。
2. 点击标题栏向上箭头查看紧凑态，点击向下箭头恢复展开态。
3. 点击页脚“演示工具”，在顶部出现的工具栏中选择场景和显示时区。
4. 选择“12 秒后到点”，观察倒计时自动变为最近公告的预计重置时间。
5. 选择“预计时间已到”“预告消失”“时间待公布”“缓存与更新失败”等场景检查文案。
6. 选择“同日多事件”，点击“本月”并选择今天，查看当天列表；选择记录后在公告区阅读。
7. 选择“长公告”，公告卡片可滚动；整个展开窗口也可滚动至日历底部。
8. 点击右上角“…”选择浅色、深色或跟随系统主题。
9. 右上角刷新图标会重新加载模拟场景，“12 秒后到点”会重新开始计时。
10. 点击“…”中的“退出”关闭原型。M1 尚未实现托盘、位置记忆与设置保存。

时区
“跟随电脑时区”读取电脑设置；其他选项仅改变演示显示，不修改 Windows 设置。
切换时区时对应的时间和日历分组会变化，剩余时长仍基于同一绝对时间。
公告原文保持原样，旁边的发布时间和公告板预计时间单独转换。

界面说明
◇ 表示未来预告；● 表示全局公告记录；◆ 表示备用公告记录；○ 表示其他或观察记录。
历史按公告／观察日期归档，不能把日期标记理解成个人账户已恢复额度。
到点后显示日期与时间，实际额度请以 Codex 中显示为准。
模拟公告没有真实推文链接；页脚可以打开 Codex Resets 来源网站。

开发检查入口
“…”中的“运行 M1 检查并导出快照”会自动切换场景，并在检查后关闭窗口。
输出写入程序目录旁的 captures 文件夹。该功能用于 M1 验证，不需要用于日常查看。
