Codex Reset {{VERSION}}
Windows 11 x64 · 自带 .NET 10 运行时 · 发布候选版

首次运行
1. 将 ZIP 完整解压到可读取的目录，不要直接从压缩包中运行 EXE。
2. 双击 CodexResetWidget.exe，无需另装 .NET。
3. 首次启动默认精简；网络可用时自动读取公开数据，无需账户或 API Key。

桌面操作
- 拖动标题栏空白、名称或 Logo 可以移动窗口。
- 图钉切换置顶：空心倾斜表示未置顶，蓝色实心竖直表示已置顶。
- 箭头切换精简／展开；展开后依次为倒计时、公告、日历，记住上次选择。
- 公告左右按钮翻阅已收录消息；长文在公告正文内滚动。
- 日历左右按钮切换月份，“本月”回到当前月份，点击日期查看当天记录。
- “…”可刷新之外的窗口操作、选择主题、查看关于和退出；刷新按钮手动检查公开数据。
- “×”收进托盘，首次关闭有提示；点击托盘图标恢复，右键菜单可显示、刷新或退出。
- 完全退出请选择“…”或托盘菜单中的“退出”。Win+D 遵循普通窗口行为。

时间与额度
所有日期跟随电脑系统时区，公告原文保持原样。
倒计时表示距离公告预计时间；到点后显示最近公告的预计时间，不确认个人额度已恢复。
“额度直接重置”表示直接重置当前额度；“限额重置券”表示可手动使用的重置机会，期限以 Codex 为准。
无明确时间不生成倒计时。离线有缓存时继续展示并提示；首次离线显示空状态，可刷新重试。
实际额度以 Codex 为准。

数据路径
%LocalAppData%\CodexResetWidget\settings.json：模式、主题、置顶、窗口尺寸与位置。
%LocalAppData%\CodexResetWidget\cache\snapshot.json：公开数据缓存（格式版本 1）。
%LocalAppData%\CodexResetWidget\logs\：滚动诊断日志，通常合计不超过约 1.1 MB。
应用不要求安装目录可写；不要同时运行多个版本，以免共同写入设置。

升级
1. 从旧版托盘菜单选择“退出”，确保旧程序已停止。
2. 新 ZIP 完整解压到一个新目录，运行新版 EXE。
3. 新版继续读取同一用户数据目录中兼容的设置与缓存；不会强制改变已保存的展开选择。
如需备份，可在退出后复制整个用户数据目录。不支持的格式或损坏文件会回退并提示，不阻止启动。

移除
退出后删除解压目录即可移除程序。用户数据默认保留。
需要彻底清除设置、缓存和日志时，退出后再删除 %LocalAppData%\CodexResetWidget\。
本版未创建自启动项、服务或安装登记。
